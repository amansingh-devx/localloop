# LocalLoop

Hyperlocal community & discovery platform — BMSIT&M CSE Mini Project (BCS506), 2026-27.

**Team:** Aman Kumar Singh, Devang Goel, Pranjal Thakur, Sathya Shivani
**Guide:** Dr. Madhusudhan M.V

## Stack

- **Frontend:** HTML, CSS (Tailwind), JavaScript — UI designed in Stitch
- **Backend:** Python + FastAPI
- **Database:** PostgreSQL + PostGIS
- **Search:** PostGIS radius queries + Sentence Transformers (semantic search)

## Project structure

| Folder            | What's inside                                |
| ----------------- | -------------------------------------------- |
| `frontend/pages/` | App screens (HTML)                           |
| `frontend/js/`    | Browser JavaScript that talks to the backend |
| `frontend/css/`   | Custom styles                                |
| `backend/`        | FastAPI application                          |
| `database/`       | Table schema and seed data                   |
| `docs/design/`    | Stitch design references                     |

UI screens adapted from the team's initial Stitch prototype by Sathya Shivani.
